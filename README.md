Description of the Work - An artificial intelligence enabled student support platform that provide context - aware and platform specific answers based on the queries provided. The system performs text analysis on uploaded text based documents to summarize, or to retrieve information with accuracy, helping students navigate text based course materials efficiently and also helps in platform navigation with resolving platform specific queries. 

( Technologies Used ) 
( 1 ) Artificial Intelligence Framework - Langchain, Groq api key 
( 2 ) Responsive Web - Python, Streamlit 
( 3 ) Cloud Deployment - Render
